UrbanBrew Google Analytics Assignment

This project contains THREE webpages:
- index.html
- menu.html
- about.html

Setup:
1. Deploy all files to GitHub Pages or another host.
2. Create a GA4 property and Web Data Stream.
3. Copy your Measurement ID (example: G-ABC1234567).
4. Replace every G-XXXXXXXXXX in all HTML files with your real ID.
5. Redeploy.
6. Open all pages several times.
7. Check Google Analytics > Reports > Realtime.
8. Later take a screenshot from Reports > Reports snapshot.

Bonus:
The Explore Menu button sends the custom event: view_menu_click
